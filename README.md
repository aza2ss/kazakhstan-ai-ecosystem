# KAZAI — AI-экосистема Казахстана

Локальная платформа каталога AI-команд и продуктов Казахстана и Центральной Азии, а также технологических хакатонов. Публичные карточки показывают источники; предложенные проекты попадают в очередь модерации. Администратор управляет записями через защищённый раздел.

## Возможности

- Каталог стартапов с серверным поиском, географией, направлением и сортировкой.
- Подробные страницы стартапов и событий.
- Форма предложить проект: серверная валидация, ссылка на источник, согласие и очередь модерации.
- SQLite база с миграцией, индексами, внешним ключом и журналом администраторских действий.
- Админ-панель: вход, просмотр заявок, публикация или отклонение, создание/изменение/снятие с публикации проектов и событий.
- Роли `admin` и `editor`; нет публичной регистрации администраторов.
- Сессии в HttpOnly/SameSite cookie, пароль scrypt, защита SQL параметризованными запросами, ограничения частоты запросов, проверка входных данных, экранирование вывода и защитные HTTP-заголовки.
- Адаптивный интерфейс на русском, казахском и английском. Шрифт выбирается из SamsungOne / Samsung Sharp Sans, если он установлен в системе; иначе используется веб-шрифт Roboto и системные sans-serif fallback. Файлы шрифтов Samsung не распространяются в проекте.
- Статус хакатона рассчитывается отдельно от регистрации; календарь и отображение дат используют `Asia/Almaty`. Регистрация не открывается автоматически после дедлайна.

## Архитектура

- Node.js 22.13+ (используется встроенный `node:sqlite`; зависимости npm не нужны).
- Backend: REST API на встроенном `node:http`.
- База данных: SQLite (`data/kazai.sqlite`), создаётся автоматически при первом запуске.
- Структура: `server.mjs`, `migrations/001_initial.sql` и `migrations/002_startup_geography.sql`, `src/`, `data/catalog.json`, `tests/`.
- Сервер одновременно отдаёт статические HTML/CSS/JS и `/api/*`.

## Запуск на Windows

Откройте PowerShell в корне проекта. Проверьте Node:

```powershell
node --version
```

Нужен Node.js 22.13 или новее. Зависимости устанавливать не надо.

```powershell
$env:PORT = '4173'
node server.mjs
```

Откройте <http://localhost:4173>. Не открывайте HTML через `file://`: форма и каталог используют API сервера.

## Администратор

Создайте первую учётную запись в другом PowerShell окне, находясь в корне проекта:

```powershell
node server.mjs admin:create admin@example.kz "Ваш-длинный-пароль-не-короче-12"
```

Команда пишет учётную запись в ту же SQLite базу. В `/admin.html` войдите указанными данными. Публичного signup нет. Пароль хранится как salted scrypt hash, не в исходниках.

## Конфигурация и production

Скопируйте `.env.example` в `.env` как памятку и задайте переменные в оболочке запуска (сервер пока не загружает `.env` автоматически):

```powershell
$env:SESSION_SECRET = [Convert]::ToHexString([Security.Cryptography.RandomNumberGenerator]::GetBytes(32))
$env:NODE_ENV = 'production'
$env:PORT = '4173'
node server.mjs
```

В production `SESSION_SECRET` обязателен. TLS должен завершаться на доверенном reverse proxy; переменная production добавляет `Secure` к cookie. Не публикуйте SQLite файл или `.env`.

## API

- `GET /api/health`
- `GET /api/startups?q=&geo=&industry=&sort=`
- `GET /api/startups/:id`
- `GET /api/events`, `GET /api/events/:id`
- `POST /api/submissions`
- `POST /api/auth/login`, `GET /api/auth/me`, `POST /api/auth/logout`
- За сессией: `GET /api/admin/submissions`, `PATCH /api/admin/submissions/:id`
- За сессией: `GET|POST /api/admin/startups`, `PATCH|DELETE /api/admin/startups/:id`
- За сессией: `GET|POST /api/admin/events`, `PATCH|DELETE /api/admin/events/:id`

`DELETE` в админке снимает публикацию мягко, запись остаётся в базе и журнале.

## База и резервное копирование

При старте автоматически применяется SQL схема `migrations/001_initial.sql`; начальные карточки загружаются из `data/catalog.json` только при пустой таблице проектов и событий. Данные сохраняются в `data/kazai.sqlite`.

Перед обновлением остановите сервер, затем скопируйте `data/kazai.sqlite` в защищённое место. Файл содержит заявки и email контакты, поэтому обращайтесь с ним как с приватными данными.

## Тесты

```powershell
npm test
```

Интеграционный тест поднимает изолированный экземпляр сервера с временной SQLite базой и проверяет здоровье API, seeded-каталог, поиск и географию, хакатон, отправку заявки, ограничение доступа, вход, модерацию, создание/изменение/снятие проектов и событий, выход. Внешние сайты тест не открывает.

## Данные каталога и ограничения

В каталоге 6 записей: Sergek Group, Cerebra AI, Documentolog, Beyne.ai, Higgsfield AI, zypl.ai. Для каждой отдельно хранятся страна происхождения, страна регистрации, расположение команды и география деятельности; неизвестные поля честно помечаются как не подтверждённые. Описания имеют публичные ссылки, но перед широкой публичной эксплуатацией администратор должен перепроверить свежесть продуктовых описаний и первичные источники. Новые записи добавляются только при наличии публичного источника.

Запись о MITU Hackathon 2026 перенесена из исходного ТЗ: даты 20–21 ноября, Алматы, MITU, адрес и три темы. Точные часы начала/окончания в исходной записи отсутствуют; система использует календарные границы дат в часовом поясе Алматы, явно отмечая отсутствие подтверждённого расписания.
