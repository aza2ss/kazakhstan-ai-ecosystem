# HACKATHONS_IMPORT_REPORT

## Текущий снимок каталога

Данные обновлены **21 ноября 2026 года** из публичного каталога [hackathon.kz](https://hackathon.kz/events) и его [API событий](https://api.hackathon.kz/api/events?period=2026&limit=100&offset=0). API вернул 126 событий за 2026 год, из них 56 имеют тип «хакатон». В снимок Startup Hub попали **40 хакатонов hackathon.kz**: все 13 активных или предстоящих на дату обновления и 27 недавно завершившихся.

Отдельная карточка MITU и старые записи из другого календаря удалены из каталога. В список не включаются буткемпы, питчи и конференции, если источник не классифицирует их как хакатоны. Повторный импорт автоматически использует дату Казахстана и обновляет набор из API.

## Какие поля берутся из источника

| Поле | Источник/правило |
|---|---|
| Название, тип, даты, город и площадка | Публичная карточка hackathon.kz |
| Организатор, темы, условия и приз | Переносятся, если опубликованы |
| Регистрация и официальная ссылка | URL из исходной записи |
| Афиша и галерея | URL изображения из исходной записи, без случайных подстановок |
| Дедлайн и описание | Заполняются только при наличии в источнике |
| Координаты | Центр города только для известных городов; адрес не угадывается |
| Страница источника | `https://hackathon.kz/hackathon?slug=<slug>` |

Незаполненные источником сведения остаются пустыми. Статусы мероприятия вычисляются по календарным датам с часовым поясом `Asia/Almaty`; регистрация показывается отдельно от статуса самого хакатона.

## Обновление

Запустить в PowerShell из корня проекта:

```powershell
./scripts/import-hackathons.ps1
```

Скрипт запрашивает обе страницы API и facets, включает актуальные хакатоны и дополняет выборку недавно завершёнными до 40 карточек. База синхронизирует записи по slug; снятые источником события перестают отображаться публично.
